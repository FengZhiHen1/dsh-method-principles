# 提示词段机制

## 权威范围

本文唯一拥有本插件的段注册契约、默认文案、配置解析、装配位置、生命周期与失败语义。需求与验收条件归 `../需求.md`，模块与命名约定归 `../项目结构设计.md`，部署与验证流程归 `部署.md`。本文不定义部署步骤。

## 结论先行

- 机制只有一个：`apply` 中注册一个全局系统提示词段，文本来自 `Config.text`（默认文案），副作用绑定 `ctx.effect()`。
- 段的三个契约值：名称 `deployment:method-principles`、order `200`、不设 `complete`。
- 装配结果里该段为空字符串时被丢弃，因此 `text: ''` 等价于关闭该段。

## 段契约

| 字段 | 值 | 约束 |
|---|---|---|
| `name` | `deployment:method-principles` | 全局唯一；同 layer 内重名导致挂载失败，跨 scope 重名被遮蔽 |
| `order` | `200` | 自取唯一数值；位于 `deployment:persona`(0) 之后、`plan:policy`(500) 之前 |
| `text` | `Config.text`（默认文案） | 纯静态字符串；不得含 `{{...}}` 变量引用 |
| `complete` | 不设 | 设 `true` 会使本段成为唯一提示词，且多段 complete 直接装配失败 |

- 注册方式：`ctx.effect(() => ctx.systemPrompt.section({ name, order, text }), '<标签>')`；`section()` 返回该注册的 disposer，`ctx.effect` 负责在 fiber dispose 时调用它。
- 不注册动态上下文（`ctx.systemPrompt.context`）、不注册变量（`ctx.systemPrompt.variable`）、不注册工具 schema（`ctx.systemPrompt.tools`）。

## 默认文案

默认文案是包内常量（`DEFAULT_PRINCIPLES_TEXT`），不传 config 时生效。逐字内容如下（8 条 + 1 行标题 = 9 行，约 150 词）：

```text
Working principles:
- First principles: before changing anything, confirm the problem exists and reproduces, name the root cause, and state the success criteria and what will change after the fix.
- Adversarial review: have a reviewer with no implementation context hunt for counterexamples, gaps, and failure cases, and demand evidence for each.
- Ablation: to prove a rule, tool, or step matters, remove it, keep everything else fixed, re-run, and compare.
- Occam's razor: start from the simplest version that works and let structure follow real demand.
- Surface uncertainty: state which conclusions lack evidence, which cases are untested, and where you are guessing.
- Judge first: form your own conclusion and basis before reading another agent's answer.
- Critical thinking: separate what you observed from what you inferred, and say what evidence would overturn your judgment.
- High cohesion, low coupling: keep related logic together and isolate modules behind clear interfaces, so each change has a bounded blast radius.
```

各条与附图原则的对应关系（编号仅用于溯源，不进提示词）：

| 行 | 附图原则 |
|---|---|
| 1 | ① 第一性原理 |
| 2 | ② 对抗式审查 |
| 3 | ③ 消融实验 |
| 4 | ④ 奥卡姆剃刀 |
| 5 | ⑤ 列出不自信的点 |
| 6 | ⑥ 保持独立思考 |
| 7 | ⑦ 批判性思维 |
| 8 | ⑧ 高内聚低耦合 |

## 配置解析

- `Config` 为 Schemastery schema：`text: z.string().default(DEFAULT_PRINCIPLES_TEXT)`；loader 在 `apply` 之前校验并填默认值，`apply` 始终收到完整配置。
- 覆盖语义：profile patch 按 id 定位行，**整体替换 config 值**（不是深合并）。用户只写 `text` 即保留默认语义。
- 关闭语义：`text: ''` → 装配结果中该段被 `renderPrompt` 的"过滤空段"规则丢弃，等价于该段不存在；插件仍挂载、无报错。
- 非法值：`text` 传非字符串 → 挂载失败（fiber FAILED），错误信息含配置路径。
- 未知键：Schemastery 在默认（非 strict）模式下把未知键原样并入结果，插件只读 `text`、不为此额外报错；本插件不做未知键拒绝。

## 装配位置与可见范围

```text
harness:identity (-1000)
harness:source (-900)
app:web-surface (-800)
deployment:persona (0)
deployment:method-principles (200)   ← 本插件
plan:policy (500)
tools:ptc-only (800) … 各工具段 (1000–2900)
tools:sdk (5000) … ui:deliverable-file-references (9000)
```

- 可见范围：全局注册 → 全部 agent（含子代理）可见，不依赖 preset 选择。
- 遮蔽规则：scoped 段遮蔽全局同名段。本段名在用户的插件集合中保持唯一时不会被遮蔽；一旦有其他段使用同名，本段会**整体消失**而非叠加。

## 生命周期

| 阶段 | 行为 |
|---|---|
| 挂载 | fiber ACTIVE 时注册段；注册与 disposal 都会触发 `system-prompt/change` |
| 卸载 | `ctx.effect` 的 disposer 注销段；装配结果中不再出现该段 |
| 重挂 | 重新注册同名段，不产生重复段（同一 layer 内同名注册会抛错，故必须先注销） |
| 重载 | 源码改动后重启 profile 生效；bundle 成员变化必须重启实例 |

## 失败语义

| 故障 | 形状 | 处置 |
|---|---|---|
| `systemPrompt` 服务缺失 | fiber 停 PENDING，启动输出出现 `N entries did not activate` | 检查该 profile 是否装载了提供 `systemPrompt` 的基础 bundle |
| 配置非法 | 挂载失败（fiber FAILED），报 `invalid config` 与路径 | 按报错修正 config |
| 段名重复（同 layer） | 挂载失败，报 `prompt section "…" is already registered` | 确认同一 profile 未重复挂载本插件 |
| 文案含未注册变量 | 该 scope 装配失败，报 `unknown prompt variable` | 文案中移除 `{{...}}` |

## 验证

- 单元：`../../test/config.test.mjs`（默认值/覆盖/空串/非法值）、`../../test/section.test.mjs`（段名、order、文本逐字断言、无 `complete`）。
- 生命周期：`../../test/lifecycle.test.mjs`（挂载→卸载→重挂，断言段无残留、无重复）。
- 组合：`../../test/composition.test.mjs`（`cordis.patch.yml` 过 Loader 的行断言）。
- 端到端：Web UI 的系统提示词折叠行展开后逐字核对本段位置与内容；子代理会话同样核对（步骤见 `部署.md`）。

## 非目标

- 不提供逐条原则的独立开关、不做多段拆分、不做文案模板变量。
- 不做按 scope 变化的文案（不依赖 `AssembleContext`）。
- 不修改或重排任何 DSH 原生段。
